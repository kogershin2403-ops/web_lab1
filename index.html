Өзім туралы

Сәлем! Бұл менің HTML және CSS көмегімен жасаған алғашқы веб-бетім. Мен веб-бағдарламалауды үйреніп жатырмын және жаңа технологияларға қызығушылық танытамын. Осы зертханалық жұмыста HTML құрылымын жасауды және CSS көмегімен веб-бетті әдемі безендіруді үйрендім.
